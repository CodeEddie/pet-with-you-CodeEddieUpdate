将大肥鱼拖到任务栏附近松手，待机时双脚会按当前尺寸对齐所在屏幕的任务栏上沿。

- 在「屏幕、任务栏和 GPT 窗口」模式下，脚底靠近任务栏时会优先吸附到任务栏。
- 轻点桌宠或打开尺寸菜单会保留当前吸附位置。

在 **Assets** 中下载 `pet-with-you-1.0.5-x64-setup.exe`。从 CodeEddie v1.0.4 升级时，先退出桌宠，再运行安装程序并沿用原安装目录。安装包适用于 Windows 10/11 x64，尚未签名，可用同页的 `SHA256SUMS.txt` 校验文件。
