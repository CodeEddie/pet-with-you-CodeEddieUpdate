这是 CodeEddie Update 的首个 Windows 10/11 x64 安装版，基于 [Refining-colors/pet-with-you v1.0.2](https://github.com/Refining-colors/pet-with-you/releases/tag/v1.0.2)。

- 8 个时段播放原版动画小剧场，六类工作状态共有 17 个候选动作。
- 过滤无法恢复的 Codex 会话卡片，减少点击后出现的 `no rollout found`。
- 右键“发给大肥鱼看”，可根据标题、字幕、分享文字或视频生成并复制评论草稿。视频读取和转录所需组件见 [配置说明](https://github.com/CodeEddie/pet-with-you-CodeEddieUpdate/blob/v1.0.3/docs/VIDEO_DRAFT.md)。
- 安装包使用 Electron 45.3.0，包含运行环境的安全修复。

下载 `pet-with-you-1.0.3-x64-setup.exe`。安装包自带运行环境，默认以纯桌宠模式启动。从 1.0.2 升级时，先从托盘退出桌宠，再运行安装程序并沿用原安装目录。安装包尚未签名，可用同页的 `SHA256SUMS.txt` 校验文件。

角色与 106 段动画来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，沿用原作署名和非商用条件。代码采用 MIT。
