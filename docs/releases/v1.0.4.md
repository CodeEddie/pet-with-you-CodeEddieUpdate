本版修复了调整大肥鱼大小时，对话字号不随窗口变化的问题。

- 右键调整桌宠尺寸后，输入框、回复、任务卡片、进度和错误提示、视频草稿操作区的字号会同步缩放。默认尺寸沿用原字号。
- 已打开的对话即时调整布局，保留未发送的文字和文字选区。

在 **Assets** 中下载 `pet-with-you-1.0.4-x64-setup.exe`。从 CodeEddie v1.0.3 或上游 v1.0.2 升级时，先从托盘退出桌宠，再运行安装程序并沿用原安装目录，无需先卸载。安装包适用于 Windows 10/11 x64，尚未签名。可用同页的 `SHA256SUMS.txt` 校验文件。
